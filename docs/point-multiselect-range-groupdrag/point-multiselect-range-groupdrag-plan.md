# point-multiselect-range-groupdrag — план

## Требование владельца (2026-07-23), verbatim

> 1. Shift-Click должен селектировать все точки, находящиеся между последней выбранной и текущей.
> 2. Если выбрано несколько точек и происходит Ctrl-drag, то должны подвинутся все выбранные точки.

Контекст: продолжение `point-mode-removal`. Мультивыбор точек по Ctrl/Shift уже перенесён на
обычный график (жест: модификатор + нажатие-отпускание вершины без движения → toggle точки в
мультивыборке; Ctrl+drag двигает одну вершину). Сейчас **Ctrl и Shift делают одно и то же**
(оба — toggle одной точки), а drag всегда двигает ровно одну вершину. Владелец разводит их:

- **Req 1** — Shift получает семантику диапазона (range-select), Ctrl остаётся точечным toggle.
- **Req 2** — drag выбранной вершины при непустой мультивыборке двигает всю группу.

## Что где сейчас (инвентаризация)

| Место | Текущее поведение |
|---|---|
| `GTrackView.onPointerDown` | Ctrl/Shift + вершина → `beginVertexDrag(hit, multiSelect=true)` |
| `GTrackView.beginVertexDrag` | под модификатором `select-point` откладывается (PM-D2) |
| `GTrackView.onPointerMove` (1-е движение) | если `dragMultiSelect` → эмитит `select-point` (хост чистит мультивыбор) и дальше двигает ОДНУ вершину |
| `GTrackView.onPointerUp` (клик без движения) | `multiSelect` → `toggle-multi-select`, иначе `edit-point` |
| `use-gtrack-lanes.toggleMultiSelect` | toggle одной точки (сидит одиночную selection, GT10.42) |
| `use-gtrack-lanes.dragPoint` | двигает ОДНУ вершину (clamp/crossover); crossover сбрасывает мультивыбор голоса |
| `TracksPanel` | `@toggle-multi-select`, `@drag-*` проброшены в стор |

## Решения

- **MSR-D1 (Req 1).** Shift+клик по вершине = диапазонный выбор от **якоря** до текущей точки
  включительно, в пределах ОДНОГО голоса, объединяя (union) с уже накопленной мультивыборкой.
  Якорь = последняя одиночно выбранная (`selection`) либо последняя Ctrl-toggle-нутая точка;
  Shift-range якорь НЕ сдвигает (можно расширять диапазон повторным Shift+кликом). Ctrl+клик —
  прежний точечный toggle. Новый эмит `range-multi-select`; хост → `rangeMultiSelect`.
- **MSR-D2.** Кросс-голосовой диапазон не определён (точки разных голосов не упорядочены общей
  осью индексов). Shift+клик по вершине другого голоса, чем якорь, добавляет только её и переносит
  якорь туда (деградация до toggle-add).
- **MSR-D3 (Req 2).** Групповой drag: если схваченная вершина ∈ мультивыборке и её размер ≥ 2 —
  тянутся ВСЕ выбранные точки жёстким блоком. Семантика **clamp** (не crossover): общий Δвремени
  зажимается так, чтобы ни одна выбранная точка не перешла невыбранного соседа → индексы стабильны,
  ключи `voiceId:pointIndex` не рассыпаются. Δзначение применяется к каждой точке через
  `valuePatchForMode` (клампинг по режиму — per-point). Оригиналы снимаются один раз на первом кадре.
- **MSR-D4.** Групповой drag НЕ эмитит `select-point` (иначе хост очистит мультивыбор) и не трогает
  одиночную `selection`; мультивыбор сохраняется после отпускания. Одна транзакция = один undo.
- **MSR-D5.** Различение по модификатору откладывается до pointerup, как и раньше: press-release без
  движения по вершине = toggle-out (Ctrl) / range (Shift); реальное движение по ВЫБРАННОЙ вершине =
  групповой drag; движение по НЕвыбранной вершине под модификатором — прежний одиночный drag
  (эмитит `select-point`, что осознанно очищает мультивыбор).

## Шаги

- **MSG0.1** — план + progress.json.
- **MSG1.1 (Req 1)** — range-select: `GTrackView` запоминает модификатор жеста (`dragRange`), на
  клике без движения эмитит `range-multi-select` для Shift; стор — `rangeMultiSelect` + якорь
  (`multiAnchor`), обновляемый в `selectPoint`/`toggleMultiSelect`. Проброс в `TracksPanel`.
- **MSG2.1 (Req 2)** — group drag: `GTrackView` определяет `dragGroup` (hit ∈ `multiSelected`,
  size ≥ 2), подавляет отложенный `select-point`; стор — групповое перемещение блока в `dragPoint`
  (снимок оригиналов, зажатый Δвремени, per-point `valuePatchForMode`), сброс на end/cancel.
- **MSG3.1 (PAUSE)** — приёмка владельцем в реальном приложении.

## Риски

- **R1** — очистка мультивыбора через `@select-point` (та же ловушка, что PM-D2): в групповом drag
  нельзя эмитить `select-point`. Митигация — MSR-D4/D5.
- **R2** — рассыпание ключей `voiceId:pointIndex` при пересортировке. Митигация — clamp-семантика
  группового drag (MSR-D3) держит индексы стабильными.
- **R3** — расхождение между `dragGroup` (считается в компоненте по пропу) и групповой веткой стора
  (считается по `multiSelection`). Оба смотрят на один и тот же `Set` — держать критерий идентичным
  (size ≥ 2 && содержит ключ).
