## 3. Решения

- **WS-D1 — одна шестерёнка на группу, в тайтл-баре.** Вместо двух per-канальных гиров в области
  графики (SF27) — одна кнопка `settings` в правом краю fold-хедера «Общая волна» (после заголовка;
  `flex:1` заголовка сам прижмёт её вправо), `@click.stop` (не задевать Ctrl-click/фолд поведение
  хедера). Открывает диалог на вкладке «Оба канала». Быстрый доступ к каналу — вкладками (req 5).
- **WS-D2 — форма диалога по образцу GT10.29, inline в TracksPanel.** `q-card` → `row no-wrap` →
  узкий `q-list` (~160px, `clickable` + `active-class`) + `q-separator vertical` + широкая панель
  контента; свои классы `tracks-panel__wf-settings-*`. В отдельный компонент не выделяем: состояние
  и персистентность живут в TracksPanel, контролов три, и все диалоги TracksPanel (SF26 minimap,
  gtrack, SF27) — inline; выделение добавило бы только props/emits-обвязку.
- **WS-D3 — REVISED (owner req 6) — модель вкладок + тоггл «Применить к обоим каналам».** Состояние:
  `waveformSettingsOpen: boolean` + `waveformSettingsTab: 'both' | 0 | 1` (вместо сегодняшнего трюка
  «channel|null») + `waveformLinkChannels: boolean` (персистится, дефолт **ON**). Тоггл — на форме
  «Оба канала», над настройками (req 6, дословно). Семантика:
  - **ON (дефолт):** форма «Оба канала» активна и правит **свою** сущность (WS-D9, req 12 —
    прежняя запись «в оба канала» отменена); пункты «Левый»/«Правый» — `:disable` (req 6).
  - **OFF:** «Левый»/«Правый» активны, каждый правит свой канал; контролы формы «Оба канала»
    **выключены** (жив только сам тоггл). Иначе форма противоречила бы своему лейблу: «применить к
    обоим» выключено, а форма всё равно писала бы в оба.
  - **REVISED (req 11): флип тоггла применяется мгновенно.** Тоггл **выбирает источник отрисовки**:
    `linked → каждый канал рисует сущность «Оба канала»`, иначе — свою. Поэтому ничего не
    копируется и не «выравнивается» — меняется источник, а L/R-сущности остаются нетронутыми
    (req 12). Флип обратно в OFF **возвращает** каждому каналу его собственные настройки — операция
    полностью обратима (это закрывает прежний риск «undo нет»).
  - **get на «Оба канала» читает свою сущность** (а не канал 0 — req 12). Вкладки «Левый»/«Правый»
    читают **сырые** массивы, а не `wfColor(ch)`: последний отвечает на вопрос «что канал
    *рисует*», а это при `link=ON` — сущность «Оба канала»; иначе три сущности перестали бы быть
    независимыми на экране.
  - Дефолт тоггла **ON** — подтверждён владельцем 2026-07-15 («Согласен дефолт тоггла ON»).
    Следствие см. R1.
- **WS-D4 — REVISED (owner req 7) — моно-файл: один пункт «Моно».** `isSpectrogramStereo === false`
  → в списке единственный пункт с ярлыком «Моно» (внутренний id вкладки остаётся `'both'` — это
  «единственная/общая» область; меняется только ярлык), «Левый»/«Правый» скрыты, **тоггл скрыт**
  (при одном канале «применить к обоим» бессмысленно), форма правит канал 0.
- **WS-D5 — overlay и лейны не переезжают.** Гир на спектрограмме в overlay-режиме остаётся (стек
  волны и его тайтл-бар в overlay не существуют — переносить некуда) и открывает новый диалог с
  вкладкой своего канала. **REVISED (req 6):** при `waveformLinkChannels === true` вкладка канала
  заперта, поэтому любой per-channel вход ведёт на «Оба канала»:
  `openWaveformSettings(ch)` → `tab = link ? 'both' : ch` (то же правило — для per-канальных гиров
  дорожек, пока они живы в WS1.1). Гиры лейнов gtrack (per-lane настройки) — без изменений.
- **WS-D6 — WaveformView: проп `showSettingsGear`, default `true`.** Через `withDefaults` (не
  «голый» type-only boolean — absent-проп кастуется в `false`, см. правило про Vue boolean): лейны
  ничего не передают и не меняются, overall-стек передаёт `:show-settings-gear="false"`. Эмит
  `open-settings` остаётся. Симметрично прецеденту GT10.3 в SpectrogramView (там же имя пропа),
  только с обратным дефолтом.
- **WS-D7 — набор настроек не меняется, персистентность +2 ключа.** Цвет / шкала lin-dB /
  прозрачность наложения (последняя, как сейчас, видна только при `viewMode === 'overlay'`). Ключ
  localStorage прежний (`mindwave-tracks-waveform`), формат получает `link: boolean` (WS-D3) и
  `both: {scale, color, opacity}` (WS-D9 — третья сущность обязана переживать перезагрузку так же,
  как две другие). Оба обратно совместимы: отсутствуют → дефолт/сид из канала 0.
- **WS-D9 — (owner req 12) три независимые сущности настроек, тоггл выбирает источник.**
  «Оба канала» — **третья** сущность (`waveformBothScale/Color/Opacity`), а не массовая запись в L и
  R. Правка любой из трёх не трогает две другие. Что **рисует** дорожка: `linked → сущность «Оба
  канала»`, иначе — своя (`wfScale/wfColor/wfOpacity` инкапсулируют правило, поэтому оверлей на
  спектрограмме и полоска в хедере подчиняются ему автоматически). Миграция: сущность «Оба канала»
  сидируется из канала 0 — именно его значения показывала вкладка «Оба канала» в WS1.1.
  **Моно игнорирует тоггл целиком**: при одном канале объединять нечего, поэтому вкладка «Моно» —
  это сущность канала 0 (WS-D4), иначе один график подчинялся бы двум разным сущностям.
- **WS-D10 — (owner req 10) свой колорпикер вместо `<input type="color">`.** Нативный инпут
  открывает пикер **браузера** — это его chrome, добавить туда иконку Close нельзя. Поэтому цвет
  выбирается кружком-образцом + `q-color` в `q-popup-proxy` с кнопкой X — **ровно тот паттерн,
  который владелец сам задал для цветов лейнов** в GT10.20 (`TracksPanel.vue`, диалог настроек
  лейна: «open to the RIGHT of the circle, with a close (X)»), с переиспользованием его же классов
  `tracks-panel__color-swatch` / `tracks-panel__color-popup`. У `QPopupProxy` нет пропа `disable`,
  поэтому в выключенном состоянии формы поповер снимается через `v-if` (+ класс `disabled` и
  `tabindex="-1"` на кружке). Правило `.audio-page__wf-color` удалено вместе с его единственным
  пользователем.
- **WS-D8 — тексты (i18n ru+en).** Новый ключ `audio.waveformSettingsTitle` («Настройки отображения
  волны» / "Waveform display settings") — заголовок диалога и тултип/aria новой кнопки; ключи
  вкладок `audio.waveformChannelsBoth/Left/Right` («Оба канала» / «Левый» / «Правый», en: "Both
  channels" / "Left" / "Right") + `audio.waveformChannelMono` («Моно» / "Mono", req 7) +
  `audio.waveformApplyBoth` («Применить к обоим каналам» / "Apply to both channels", req 6).
  Формулировка «Оба канала» подтверждена владельцем (req 8) — R6 закрыт. Существующий
  `audio.waveformStyle` остаётся — его используют гиры лейнов в WaveformView.

## 6. Верификация (каждый шаг)

- `bun run typecheck` + `bun run build` из `MindWaveCore/ui` (vue-tsc тянет GnauralCore по графу
  импортов; **не** `bunx vue-tsc` — мисматч TS).
- `bun test ui server` из GnauralCore — существующие сьюты остаются зелёными (новых тестов нет:
  фича — Vue-разметка без чистой логики).
- Ручной прогон реального приложения (главная проверка): стерео-файл — тоггл **ON**: «Левый» и
  «Правый» недоступны (req 6), оба канала рисуются настройками «Оба канала», правка применяется
  сразу (req 11); тоггл **OFF**: каждый канал **возвращает** свои настройки (req 12 — они не были
  затронуты), Л/П доступны и правят только свой канал, контролы формы «Оба канала» выключены;
  цвет — свой пикер с иконкой X в заголовке (req 10); шестерёнка отстоит от правого края так же,
  как отстояла на графике (req 9); закрыть/открыть — все три сущности и состояние тоггла
  персистятся; режим overlay — гир на спектрограмме открывает диалог (при ON — на «Оба канала»),
  слайдер прозрачности виден только тут; лейны gtrack — их гир по-прежнему открывает per-lane
  настройки; моно-файл — в списке один пункт «Моно», тоггла нет; fold/eye/Ctrl-click хедера не
  сломаны.
