# wave-settings-dialog — шестерёнка в тайтл-бар «Общей волны» + двухпанельный диалог настроек

**Owner request (2026-07-15):** «Перенос иконки-шестерёнки из области графики дорожек общей волны в
тайтл бар этого графика. В новом диалоге, который будет открываться при клике на эту кнопку должно
быть две панели: узкая слева и широкая по центру. В левой панели отображается список из трёх
элементов-закладок "Обе канала", "Левый", "Правый". В центральной части находятся настройки для
отображения волны. Настройки применябтся в зависимости от текущей активной вкладки слева.»
*(цитата дословная, с опечатками исходника: «Обе канала», «применябтся»)*

Ledger (authoritative): [wave-settings-dialog-progress.json](wave-settings-dialog-progress.json).
Методология Plan+Ledger — как в [tooltip-placement](../tooltip-placement/tooltip-placement-plan.md) /

## 1. Требования владельца (дословно → нумерованно)

1. Иконка-шестерёнка **переносится из области графики** дорожек общей волны **в тайтл-бар** этого
   графика.
2. Клик по этой кнопке открывает **новый диалог** из **двух панелей**: **узкая слева**, **широкая
   по центру**.
3. В левой панели — **список из трёх элементов-закладок**: «Обе канала» *(грамматически — «Оба
   канала», см. R6)*, «Левый», «Правый».
4. В центральной части — **настройки для отображения волны**.
5. Настройки **применяются в зависимости от текущей активной вкладки** слева.

**Owner answers (2026-07-15, на вопросы WS1.3):**

   слева "Левый" и "Правый" **становятся недоступны**.» *(заменяет прежний вопрос про индикацию
   расхождения L/R)*
7. «**Моно-файл - один пукт "Моно"**» *(→ WS-D4)*

## 3. Решения

- **WS-D1 — одна шестерёнка на группу, в тайтл-баре.** Вместо двух per-канальных гиров в области
  графики (SF27) — одна кнопка `settings` в правом краю fold-хедера «Общая волна» (после заголовка;
  `flex:1` заголовка сам прижмёт её вправо), `@click.stop` (не задевать Ctrl-click/фолд поведение
  хедера). Открывает диалог на вкладке «Оба канала». Быстрый доступ к каналу — вкладками (req 5).
- **WS-D2 — форма диалога по образцу GT10.29, inline в TracksPanel.** `q-card` → `row no-wrap` →
  узкий `q-list` (~160px, `clickable` + `active-class`) + `q-separator vertical` + широкая панель
  контента; свои классы `tracks-panel__wf-settings-*`. В отдельный компонент не выделяем: состояние
  и персистентность живут в TracksPanel, контролов три, и все диалоги TracksPanel (SF26 minimap,
  gtrack, SF27) — inline; выделение добавило бы только props/emits-обвязку.
- **WS-D3 — REVISED (owner req 6) — модель вкладок + тоггл «Применить к обоим каналам».** Состояние:
  `waveformSettingsOpen: boolean` + `waveformSettingsTab: 'both' | 0 | 1` (вместо сегодняшнего трюка
  «channel|null») + `waveformLinkChannels: boolean` (персистится, дефолт **ON**). Тоггл — на форме
  «Оба канала», над настройками (req 6, дословно). Семантика:
  - **ON (дефолт):** форма «Оба канала» активна, `wfDlg*` set пишет в **оба** канала; пункты
    «Левый»/«Правый» — `:disable` (req 6).
  - **OFF:** «Левый»/«Правый» активны, каждый правит свой канал; контролы формы «Оба канала»
    **выключены** (жив только сам тоггл). Иначе форма противоречила бы своему лейблу: «применить к
    обоим» выключено, а форма всё равно писала бы в оба.
  - **Флип тоггла не меняет значений** — он только запирает/отпирает вкладки. Выравнивание каналов
    происходит лишь при реальной правке на форме «Оба канала», поэтому случайный клик по тогглу
    ничего необратимого не делает (undo в этом диалоге нет ни у одной настройки).
  - **get на «Оба канала» читает канал 0.** При расхождении (дефолты L/R расходятся *by design* —
    §2.4) форма показывает значение левого, пока первая правка не выровняет оба; у
    `<input type="color">` смешанного состояния нет, поэтому индикацию «значения различаются» не
    строим. Дефолт тоггла (ON) — единственный оставшийся вопрос на PAUSE, см. R1.
- **WS-D4 — REVISED (owner req 7) — моно-файл: один пункт «Моно».** `isSpectrogramStereo === false`
  → в списке единственный пункт с ярлыком «Моно» (внутренний id вкладки остаётся `'both'` — это
  «единственная/общая» область; меняется только ярлык), «Левый»/«Правый» скрыты, **тоггл скрыт**
  (при одном канале «применить к обоим» бессмысленно), форма правит канал 0.
- **WS-D5 — overlay и лейны не переезжают.** Гир на спектрограмме в overlay-режиме остаётся (стек
  волны и его тайтл-бар в overlay не существуют — переносить некуда) и открывает новый диалог с
  вкладкой своего канала. **REVISED (req 6):** при `waveformLinkChannels === true` вкладка канала
  заперта, поэтому любой per-channel вход ведёт на «Оба канала»:
  `openWaveformSettings(ch)` → `tab = link ? 'both' : ch` (то же правило — для per-канальных гиров
  дорожек, пока они живы в WS1.1). Гиры лейнов gtrack (per-lane настройки) — без изменений.
- **WS-D6 — WaveformView: проп `showSettingsGear`, default `true`.** Через `withDefaults` (не
  «голый» type-only boolean — absent-проп кастуется в `false`, см. правило про Vue boolean): лейны
  ничего не передают и не меняются, overall-стек передаёт `:show-settings-gear="false"`. Эмит
  `open-settings` остаётся. Симметрично прецеденту GT10.3 в SpectrogramView (там же имя пропа),
  только с обратным дефолтом.
- **WS-D7 — набор настроек не меняется, персистентность +1 ключ.** Цвет / шкала lin-dB /
  прозрачность наложения (последняя, как сейчас, видна только при `viewMode === 'overlay'`). Ключ
  localStorage прежний (`mindwave-tracks-waveform`), формат получает **один** новый ключ
  `link: boolean` (WS-D3) — обратно совместимо: отсутствует → дефолт. Диалог — новая оболочка вокруг
  тех же `wfDlg*`-аккессоров.
- **WS-D8 — тексты (i18n ru+en).** Новый ключ `audio.waveformSettingsTitle` («Настройки отображения
  волны» / "Waveform display settings") — заголовок диалога и тултип/aria новой кнопки; ключи
  вкладок `audio.waveformChannelsBoth/Left/Right` («Оба канала» / «Левый» / «Правый», en: "Both
  channels" / "Left" / "Right") + `audio.waveformChannelMono` («Моно» / "Mono", req 7) +
  `audio.waveformApplyBoth` («Применить к обоим каналам» / "Apply to both channels", req 6).
  Формулировка «Оба канала» подтверждена владельцем (req 8) — R6 закрыт. Существующий
  `audio.waveformStyle` остаётся — его используют гиры лейнов в WaveformView.

- Ручной прогон реального приложения (главная проверка): стерео-файл — тоггл **ON**: «Левый» и
  «Правый» недоступны (req 6), правка на «Оба канала» меняет оба канала; тоггл **OFF**: Л/П
  доступны и правят только свой канал, контролы формы «Оба канала» выключены; флип тоггла сам по
  себе значений не меняет; закрыть/открыть — и значения, и состояние тоггла персистятся; режим
  overlay — гир на спектрограмме открывает диалог (при ON — на «Оба канала»), слайдер прозрачности
  виден только тут; лейны gtrack — их гир по-прежнему открывает per-lane настройки; моно-файл — в
  списке один пункт «Моно», тоггла нет; fold/eye/Ctrl-click хедера не сломаны.
