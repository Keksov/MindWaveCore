# voice-settings-redesign — редизайн настроек отображения голоса (дорожки)

Дата: 2026-07-16. Леджер: `voice-settings-redesign-progress.json` (авторитетный статус — там).

## 1. Требования владельца (дословно)

> 1. У каждого голоса должна быть иконка-шестерёнка в его тулбаре. Сейчас эта иконка рисуется в
>    графике, её нужно отдуда убрать.
>
> 2. Необходимо сделать редизайн формы настроек (см.скрин) Сейчас очень сложно понять, что здесь
>    происходит. Посоветуй варианты. Могу только сказать, что поле "Свои настройки спектра для этой
>    дорожки" отсюда надо убрать, т.к. у спектра будет своя иконка-шестрерёнка с вызовом диалога
>    настроек.

Скрин — диалог «Настройки дорожки (режим / голоса)» (GT2.2). На VS0.1 PAUSE владелец выбрал:
редизайн = **вариант B (две панели)**; стиль соло-волны — **за шестерёнку графика волны**;
point-mode-кнопка — **тоже в шапку**; при инлайн-спектре шестерёнка **не нужна**.

## 2. Инвентаризация (что есть в коде сейчас)

Всё в `GnauralCore/ui` (CRLF!, см. R1).

- **Шестерёнка сейчас рисуется в графике**: оверлей `gtrack-view__actions` в `GTrackView.vue:83-103` —
  две кнопки: `edit_location_alt` (point-mode) и `settings` (emit `open-settings`). TracksPanel ловит
  `@open-settings="gtrackSettingsId = lane.id"` (`TracksPanel.vue:245`).
- **«Тулбар голоса»** = пер-трековая шапка GT11.5 `tracks-panel__gtrack-header`
  (`TracksPanel.vue:149-186`): цветовая полоска, Fold/Unfold, глазок скрытых подграфиков, название.
  Шестерёнки там нет — ровно место под неё (по образцу шапок групп волны/спектра: SG3.2a, WS).
- **Ещё два входа в тот же диалог из подграфиков**: соло-волна `WaveformView` (гир внутри графика,
  `WaveformView.vue:44`, подключение `TracksPanel.vue:290`) и соло-спектр `SpectrogramView`
  (`:show-settings-gear="true"`, подключение `TracksPanel.vue:315-321`).
- **Сам диалог** (`TracksPanel.vue:572-717`), секции сверху вниз:
  1. Режим отображения (base/beat/volume/balance, `q-btn-toggle`) + тумблер «Полоса бита» (только base).
  2. «Соло-звук»: 4-позиционный toggle Выкл/Волна/Спектр/Оба + длинный hint-абзац + toggle размещения
     «Под-дорожка / Под кривыми» + (для волны) цвет-кружок с попапом `q-color` + слайдер прозрачности.
  3. Тумблер «Свои настройки спектра для этой дорожки» + аккордеон `GTrackSpectrumSettings`
     (:671-687) — **уходит** (треб. 2).
  4. «Голоса на этой дорожке» — чеклист.
  5. Футер: «Удалить дорожку».
- **Пер-дорожечный оверрайд спектра уже есть**: `laneSpectrum` individual-else-global
  (`use-gtrack-lanes.ts:276+`, резолверы `TracksPanel.vue:2186-2200`, форма `GTrackSpectrumSettings.vue`).
  Смежная фича `spectrogram-settings-scope` (SG3.x) уже сделала шестерёнку+панель для ОБЩЕГО спектра
  (scope Оба/L/R); соло-спектр дорожек она не трогает — «у спектра будет своя шестерёнка» для
  соло-спектра делается ЗДЕСЬ.
- **Образец двух-панельного диалога**: настройки общей волны GT10.29 (`TracksPanel.vue:722-810`).

## 3. Решения (все выбраны владельцем на VS0.1 PAUSE, 2026-07-16)

- **VS-D1 (место кнопок).** «Тулбар голоса» = пер-трековая шапка GT11.5. В шапку переезжают **обе**
  кнопки оверлея: шестерёнка (открывает диалог дорожки) и point-mode (`edit_location_alt`) — владелец:
  «Тоже перенести в шапку». Оверлей `gtrack-view__actions` в `GTrackView.vue` удаляется целиком;
  в графике кнопок не остаётся. Бонус: шапка видна и у свёрнутой дорожки — доступ улучшается.
- **VS-D2 (редизайн формы) = вариант B, «две панели»** — по образцу диалога волны GT10.29: слева
  список секций, справа контент выбранной. Секции: **График** (режим отображения + «Полоса бита»),
  **Соло-звук** (два независимых тумблера «Волна» и «Спектр» вместо 4-позиционного toggle, где «Оба»
  было = Волна+Спектр; + toggle размещения с говорящими подписями «Отдельным графиком ниже» / «Фоном
  под кривыми»; длинный hint → короткий caption), **Голоса** (чеклист). Настроек стиля в диалоге не
  остаётся: спектр — за шестерёнкой своего графика (VS-D3), стиль волны — за шестерёнкой своего
  графика (VS-D4). Футер «Удалить дорожку» остаётся. Заголовок — просто «Настройки дорожки».
- **VS-D3 (спектр за своей шестерёнкой) — rev 3 (владелец, 2026-07-17).** Контент — rev 2: **«в
  точности тот самый» контрол**, что в настройках программы и общего спектра, в режиме Моно
  (`SpectrogramOverridesView` + проп `mono`; лейн-адаптер маппит канальный контракт на единственный
  `laneSpectrum`-оверрайд; пресеты и «Сброс»→наследование — родной хром формы; SG-D8 auto-individual
  без изменений). Окно — rev 3: **стандартное докабл-детачбл @panel-окно, как у общего спектра**
  (не q-dialog): `lane-spectrum-panel` стейт + target-ref (одна панель, перенацеливается гиром —
  паттерн SG-D7), `LaneSpectrumSettingsDialog` (PanelWindow-хром по образцу `SpectrumSettingsDialog`),
  `LaneSpectrumSettingsRemote` + manifest-entry для detach (SS-D3: у ребёнка нет стора), хост в
  dock-wrap AudioPage. Отклонены: rev 1 (bespoke-диалог на `GTrackSpectrumSettings`, VS2.1),
  rev 2-хост (q-dialog, VS2.4). `GTrackSpectrumSettings` умирает со старой секцией диалога в VS3.1.
  При «Под кривыми» шестерёнки нет (подтверждено на VS0.1).
- **VS-D4 (стиль соло-волны) — rev 2 (владелец на VS2.3 PAUSE).** Не маленький диалог (rev 1, VS2.2 —
  отклонён), а **существующий двух-панельный диалог общей волны (WS1.1) в его моно-режиме** (WS-D4,
  вкладка «Моно»), перенацеленный на дорожку: `waveformSettingsLaneId` ≠ null → цвет/шкала/прозрачность
  пишут в лейн (`setLaneSoloWaveStyle`/`setLaneSoloWaveScale`); link-тумблер скрыт, прозрачность
  показывается всегда (питает инлайн-подложку). Для идентичности формы лейн получил `soloWaveScale`
  (lin/dB, персистится с конфигом лейна, проброшен в оба `WaveformView`).

## 6.5 Фаза 4 (добавлена 2026-07-18) — рефактор секции «График»: мультирежим

Требование владельца (дословно):

> Рефактор формы отображения графиков в настройках дорожки.
> 1. Режим отображения нужно переименовать в Реживы отображения
> 2. Все режимы нужно сразу вывести на форму в виде отдельных блоков видимых сразу (уйти от текущих
>    вкладок Ьазовая частота, Частота биений, Громкость, Баланс.
> 3. В каждом блоке должен появиться чекбокс "Отображать на графике". Какие графики выбраны, такие и
>    отображаем.

Инвентаризация: сегодня режим — **одиночный** `lane.mode` (`use-gtrack-lanes.ts:32`), его читают
рендер (`GTrackView :mode`, ось/точки), драг точек (`dragPoint(..., lane.mode)`), подпись дорожки
(`gtrackLaneLabel`), высоты (`curveHeight` — одна на дорожку), массовые действия
(`setVoiceMode`/`setAllLanesMode`/`showAllModesPerVoice` — «все режимы» реализованы как отдельные
дорожки на (голос × режим)). Чекбоксы «Отображать на графике» ⇒ **несколько режимов у одной
дорожки** — модель `mode` → `modes: GTrackMode[]` + рендер нескольких графиков-кривых в дорожке
(стеком, как соло-подграфики) + миграция персиста + перевыражение массовых действий.

- **VS-D5 (дизайн мультирежима) — owner-решения на VS4.0 PAUSE:** (а) выбранные режимы = отдельные
  графики стеком внутри дорожки (свой ресайз у каждого; рекомендую) vs наложение кривых в одном
  графике; (б) ноль выбранных — запретить снимать последний чекбокс (рекомендую) vs дорожка без
  кривых; (в) «Полоса бита» уезжает внутрь блока «Базовая частота»; (г) судьба массовых действий
  списка треков (set-voice-mode и «Показать все режимы») при modes[].
- **VS4.0** — разведка + этот план + **PAUSE** (вопросы VS-D5).
- **VS4.1** — модель: `modes: GTrackMode[]` (+`curveHeights` пер-режим), миграция stored `mode`,
  адаптация массовых действий и track-list. Verify: bun test + typecheck/build.
- **VS4.2** — секция «График» диалога: заголовок «Режимы отображения», четыре всегда видимых блока
  (Базовая частота / Частота биений / Громкость / Баланс), в каждом чекбокс «Отображать на графике»;
  «Полоса бита» в блоке базовой частоты. Verify: как VS4.1.
- **VS4.3** — рендер: стек GTrackView по выбранным режимам внутри дорожки (ось времени/плейхед/
  ресайзы/фолд), подпись дорожки при нескольких режимах. Verify: как VS4.1 + реальное приложение.
- **VS4.4** — **PAUSE:** финальная owner-приёмка фазы 4.
